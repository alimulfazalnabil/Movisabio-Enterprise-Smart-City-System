# AITCS Production Readiness Gate

## Investor-first release objective

The first deployable AITCS release is a **production-like, simulation/shadow-safe demonstration**. It must demonstrate the complete decision chain without claiming physical traffic-control certification or sending commands to roadside hardware.

## Release boundary

```text
Camera / Replay
    ↓
Perception
    ↓
Canonical Traffic Observation
    ↓
Traffic State
    ↓
Prediction / Baseline Forecast
    ↓
Candidate Signal Plan
    ↓
Safety Validator
    ↓
Approved Plan
    ↓
SUMO / Shadow Adapter
    ↓
Audit + Dashboard
```

Physical controller actuation remains **DISABLED** until the field integration gates in `ARCHITECTURE.md` and `ROADMAP.md` are independently satisfied.

## Definition of "production ready" for the investor deployment

The investor deployment is ready when:

1. CI passes.
2. Backend container builds successfully.
3. PostGIS and Redis pass readiness checks.
4. A versioned SUMO scenario starts through `SUMOAdapter`.
5. Recorded/replay traffic produces canonical traffic state.
6. Candidate signal plans are generated deterministically.
7. Every candidate passes through the safety validator.
8. Invalid/adversarial commands fail safe.
9. The full decision chain is visible in the dashboard.
10. Fixed-time baseline and optimized/safe plan are compared using reproducible SUMO runs.
11. No dashboard value is generated by random/mock telemetry.
12. Physical controller mode remains disabled for the investor deployment.

## Evidence policy

The dashboard and investor material must distinguish:

- **OBSERVED** — directly measured from a camera/sensor.
- **PREDICTED** — forecast from a validated model.
- **PREDICTED_BASELINE** — deterministic persistence benchmark.
- **SIMULATED** — generated by SUMO.
- **MODELED** — calculated from an explicit engineering model.
- **PROJECTED** — business or future scenario estimate.
- **UNKNOWN** — insufficient evidence.

No benchmark percentage, accuracy figure, congestion reduction, emissions reduction, or safety pass rate should be presented as empirical unless it comes from a reproducible experiment artifact.
